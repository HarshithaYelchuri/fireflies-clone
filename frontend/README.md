# Frontend: Fireflies.ai clone (Next.js)

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4 and shadcn/ui on Base UI primitives.
Scaffolded from [ai-website-cloner-template](https://github.com/JCodesMore/ai-website-cloner-template).

```bash
cp .env.example .env.local   # NEXT_PUBLIC_API_URL=http://localhost:8000
npm install
npm run dev                  # http://localhost:3000 (the backend must be running)
npm run check                # lint + typecheck + production build
```

See the [root README](../README.md) for architecture, the API overview and setup of the whole project.
